# 🤖 Robô vs Zumbis

**Robô vs Zumbis** é um jogo de ação onde você controla um robô de combate programado para eliminar hordas de zumbis em um mundo pós-apocalíptico. Com reflexos rápidos, armas poderosas e inimigos implacáveis, o jogador precisa sobreviver o máximo possível enquanto enfrenta desafios cada vez maiores.


## 🎮 Jogabilidade

- Controle simples e intuitivo.
- Sistema de tiro ou manual.
- Hordas infinitas de zumbis com dificuldade crescente.
- Pontuação baseada em inimigos eliminados
- 
## ⚙️ Controles

- `Setas` : mover o robô  
- `Mouse`: mirar  
- `Clique esquerdo`: atirar  

## 🚀 Requisitos

- Navegador atualizado (para versão web) **ou**
- Executável para Windows (se aplicável)
- Feito com [Construct 3](https://www.construct.net)

## 📦 Como Jogar

1. Baixe ou abra o jogo no navegador.
2. Comece a partida e mova-se pelas fases infinitas.
3. Atire nos zumbis e sobreviva o máximo que puder.
4. Alcance a maior pontuação possível!
